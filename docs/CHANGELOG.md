# 更新记录

## v0.23.1

- 图文对照：预览页绘制行级识别框；悬停或光标落在右侧文字行时预览自动切页并高亮对应位置；点击识别框跳转右侧文字；低置信行悬停高亮对应框（预览栏「对照」可开关，默认开启）
- 修复：扫描页识别框与版面分析统一使用渲染像素坐标
- 修复：保存编辑后内容按页码正确归档、页面几何与行级识别数据保留

## v0.23.0

- 项目持久化：任务自动保存到磁盘，重启软件不丢失；存档文件夹可自定义
- 低置信度标记：置信度低于 80% 的文字黄色高亮，提示人工复核
- 繁体转简体：一键全文转换（本地词典，离线）
- 目录生成：导出 Word 时自动生成带页码的目录
- Apple Silicon 加速：预留 CoreML 支持（默认关闭，设 MDUN_COREML=1 开启）
- 移除印章检测与图文对照功能（按用户决定精简）

## v0.21.0

- 识别：扫描 PDF、电子 PDF、混合 PDF、JPG/PNG/TIFF/BMP/WebP 图片
- 表格：自动识别并转成可编辑表格，导出 Excel/Word
- 公式：自动识别数学公式
- 标点修复：西文标点转全角、引号括号配对、公文六角括号〔〕
- 段落修复：碎行合并、页码删除、多级标题单独成段
- 编辑：整篇文档编辑、拼写检查、查找替换、版本恢复
- 标注：框选跳过/仅识别区域、区域局部识别（表格/公式/文字）
- 导出：Word、双层 PDF、文本、Markdown、Excel
- 安全：完全离线运行、防截图水印、审计日志
