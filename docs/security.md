# 安全设计

## 威胁模型

- 涉密文档不得离开本机：任何网络请求（DNS/TCP/UDP）都视为泄露事件；
- 磁盘上的中间数据不可被明文读取；
- 未授权机器不可运行（可选 strict 模式）；
- 操作留痕可审计。

## 保证措施

1. **零网络（FR-8.1）**
   - 代码层面：`mdun audit` 静态扫描全包 .py，除封锁器自身外无网络 API；
   - 运行层面：OfflineGuard 在 CLI/Web 启动即 patch socket（connect/getaddrinfo/create_connection），
     仅放行 127.0.0.1/::1 回环；

2. **数据加密（FR-8.2/FR-6.3）**
   - 临时数据与导出加密：SM4-CBC（国密）+ SM3 摘要，格式 MDSM4v1|salt|iv|ct|sm3；
   - 密钥派生：SM3(password + salt)；
   - 篡改检测：解密后 SM3 与存储摘要比对，不一致即报错。

3. **离线授权（FR-8.3）**
   - 机器指纹：SM3(网卡MAC|主机名|系统|架构)[:16]；
   - 许可证：Ed25519 签名（载荷含指纹/功能位/有效期/被授权方）；
   - 私钥仅存签发环境；客户端内置公钥验签；篡改即失效（已验证）。

4. **审计（FR-8.4）**
   - JSONL 追加日志（文件锁防并发损坏）：导入/识别/修复/导出事件；
   - 文件名可选 SM3 哈希化；日志可导出、防删（部署侧权限控制）。
